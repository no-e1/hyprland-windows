# hyprland-windows

Hyprland (0.57+, Lua config) that looks and behaves like Windows 11 – taskbar,
start menu, flyouts, lock screen, window snapping and virtual desktops,
mostly drawn by **winshell**, a GTK4 + layer-shell daemon in `hypr/winshell`.

## What's in it

- **Taskbar**: centered start button and pinned/running apps (drag to
  reorder, previews on hover), system tray, Wi-Fi / volume / battery,
  clock and notifications; on every screen (the extra ones get start,
  apps and the clock)
- **Start menu** (Windows key): all apps A–Z, search for apps and the files
  and folders in your home folder, power and sign-out menu
- **Flyouts**: quick settings (Wi-Fi, Bluetooth, airplane mode, do not
  disturb, brightness, volume), calendar with notification center, settings
  (Win + I), clipboard history (Win + V), volume / brightness OSD
- **Windows**: Alt+Tab with live previews, task view (Win + Tab), snapping
  with snap preview, minimize / show desktop animations into the taskbar,
  title bars (hyprbars plugin), virtual desktops spanning all screens
- **Lock screen** like Windows 11 (fingerprint supported), Win + P to
  project, display and mouse settings, Snipping Tool-style screenshots
- **winterm**, a terminal like Windows Terminal (tabs in the title bar)
- Dolphin set up like Explorer (incl. a "This PC" view), Windows 11 style
  icons, Selawik as the Segoe UI stand-in

## Folders

| Folder          | Contents                                                       |
|-----------------|----------------------------------------------------------------|
| `hypr`          | `hyprland.lua` (look, rules, binds, snapping, desktops), hyprlock, hypridle, scripts |
| `hypr/winshell` | winshell (`winshell.py`, control it with `winshell-ctl`), lock screen, winterm, tray, clipboard store |
| `swaync`        | Notification center (placed above the calendar)                |
| `rofi`          | Run dialog (Win + R), background picker (Win + W), power menu (Win + X) |
| `icons`         | Windows 11 style icons, generated by `tools/make-icons.py`     |
| `tools`         | Icon generator, Win11-modern icon theme, hyprbars and swaync build scripts and patches |
| `qt`, `fontconfig`, `fonts`, `applications`, `systemd` | Dolphin toolbar, Segoe UI substitute, winterm menu entry, swaync service drop-in |
| `waybar`, `kitty` | Old taskbar and terminal – not used anymore (winshell still reads `waybar/scripts/status.sh`) |

## Install

```sh
./install.sh               # links the configs into ~/.config, installs icons, fonts, Dolphin settings
tools/build-hyprbars.sh    # title bar plugin for the installed Hyprland (needs podman)
tools/build-swaync.sh      # optional: swaync with Windows-like slide-out animations (needs podman)
```

Existing folders in `~/.config` are moved to `<name>.bak-<timestamp>`.
Per machine (not in the repo): `hypr/monitors.lua` (written by the display
settings) and `hypr/mouse.lua` (mouse settings). Your own additions go into
`hypr/user.lua` (keyboard layout, …).

## Keyboard shortcuts

| Keys | Action |
|------|--------|
| Win / Win + S | Start menu / search |
| Win + E, Win + T, Win + B | Explorer (Dolphin), terminal, browser |
| Win + 1 / 2 / 3 | Pinned apps |
| Win + I, Win + A, Win + N | Settings, quick settings, notifications + calendar |
| Win + V, Win + R, Win + X | Clipboard history, run, power menu |
| Win + D, Win + M, Win + Home | Show desktop, minimize all, minimize others |
| Win + Tab, Alt + Tab | Task view, switcher |
| Win + ←/→/↑/↓, Win + Shift + ↑ | Snap, maximize, minimize, full screen |
| Ctrl + Win + ←/→, Ctrl + Win + D | Switch / add virtual desktop |
| Win + Shift + ←/→ | Move window to the next desktop |
| Win + P, Win + L, Win + W | Project, lock, background |
| Print / Win + Shift + S, Shift + Print | Screenshot of an area / the whole screen |
| Alt + F4, Ctrl + Shift + Esc | Close (on the desktop: shut down), Task Manager |

Touchpad: 3 fingers down/up shows the desktop / brings the windows back,
3 fingers left/right switches windows, 4 fingers left/right switches desktops.

## Requirements

Hyprland 0.57+ (Lua config), python3-gobject, gtk4, gtk4-layer-shell,
vte291-gtk4 (winterm), swaync, rofi, hypridle, hyprlock (fallback lock),
NetworkManager, bluez, wireplumber, brightnessctl, playerctl, grim, slurp,
wl-clipboard, dolphin, a polkit agent; for the settings: blueman,
pavucontrol, nm-connection-editor, gnome-system-monitor; podman to build
the plugins.
