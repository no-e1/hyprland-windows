# hyprland-windows

Hyprland (0.57+, Lua config) that looks and behaves like Windows 11.

| Folder    | Contents                                                        |
|-----------|-----------------------------------------------------------------|
| `hypr`    | Hyprland config, hyprlock, hypridle, scripts                    |
| `hypr/winshell` | Alt+Tab switcher and quick settings (GTK4 + layer shell)  |
| `waybar`  | Taskbar                                                         |
| `rofi`    | Start menu, power menu, lists                                   |
| `swaync`  | Notification center                                             |
| `kitty`   | Terminal (Windows Terminal look)                                |
| `icons`   | Windows 11 style status icons (generated by `tools/make-icons.py`) |
| `tools`   | Icon generator, hyprbars build script and patch                 |

## Install

```sh
./install.sh                 # links the configs into ~/.config and installs the icons
tools/build-hyprbars.sh      # builds the title bar plugin (needs podman)
```

Requirements: python3-gobject, gtk4-layer-shell, waybar, rofi, swaync, kitty,
NetworkManager, bluez, wireplumber, brightnessctl, grim, slurp.
