# hyprland-windows

Hyprland (0.57+, Lua-Config) im Windows-11-Stil.

| Ordner   | Inhalt                                   |
|----------|------------------------------------------|
| `hypr`   | Hyprland-Config, hyprlock, hypridle, Skripte |
| `waybar` | Taskleiste                               |
| `rofi`   | Startmenü, Power-Menü, Listen            |
| `swaync` | Schnelleinstellungen / Benachrichtigungen |

Installation: Ordner nach `~/.config/` verlinken, z. B.
`ln -s "$PWD/hypr" ~/.config/hypr`
